The official website for **OurChat** – a secure instant messaging application. This website serves as a landing page to promote the OurChat app, provide documentation links, download options, and showcase the development team.

## 🚀 Run website

### Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/SkyUOI/ourchat-website.git
cd ourchat-website
pnpm install
```

### Development

Start the development server with hot reload:

```bash
pnpm run dev
```

### Build for Production

Build the project for production:

```bash
pnpm run build
```

The built files will be in the `dist/` directory.
